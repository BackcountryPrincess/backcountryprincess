# MapleSap Screenshot Plan

## macOS

Required story:
1. Home forecast workspace open in the MapleSap macOS app.
2. Freeze-thaw/sap-run forecast area.
3. Region or field feedback area.
4. Account/dashboard state after production routes are working.
5. Support or settings/help state if included in the app.

Avoid:
- 404 routes
- Placeholder dashboard cards
- Missing API/forecast error states
- Browser chrome; capture the macOS app window

## iPhone

Required story:
1. Mobile home forecast view.
2. Forecast detail/freeze-thaw section.
3. Account sign-in or dashboard if mobile app is submitted.
4. Support/privacy access.

Avoid:
- Submitting iPhone screenshots until an iPhone build exists.

## iPad

Required story:
1. Tablet-width forecast workspace.
2. Planning/dashboard view.
3. Support/privacy access.

Avoid:
- Submitting iPad screenshots unless the iOS app is universal.
