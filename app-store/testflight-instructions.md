# MapleSap TestFlight Tester Instructions

## What To Test

1. Launch MapleSap on macOS.
2. Confirm the home screen loads.
3. Check the public forecast area.
4. Try navigation links.
5. Try account sign-in only if a test account is provided.
6. Submit field feedback only with test content.
7. Quit and relaunch the app.

## What To Report

- Blank screens
- 404 pages
- Forecast load failures
- Sign-in or password reset issues
- App launch or quit problems
- Layout issues on smaller Mac screens

## Known Pre-Submission Notes

The live site must have working API routes and legal/support pages before broad external testing.
